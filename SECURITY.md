# Security policy

## Supported versions

Security fixes are applied to the current development branch and, when
practical, to the latest stable release. Older releases are not supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue containing exploit details or sensitive information.
Include the affected version, a minimal reproduction, the expected impact,
and any suggested mitigation. If private reporting is unavailable, contact
the maintainer through the email address in `pyproject.toml` and request a
private channel before sharing details.
